VS Code installs extensions into an `extensions` folder inside your user's `.vscode` directory. Here's where that is on each OS, how to move it, and a tip for keeping extension data out of your project's git history.

## Where VS Code stores extensions

| OS | Extensions folder |
| --- | --- |
| Windows | `%USERPROFILE%\.vscode\extensions` |
| macOS | `~/.vscode/extensions` |
| Linux | `~/.vscode/extensions` |

VS Code Insiders uses `.vscode-insiders/extensions` in the same places.

To open the folder from VS Code, open the Command Palette and run **Extensions: Open Extensions Folder**.

### Change the extensions folder

Launch VS Code with the `--extensions-dir` flag to use a different location:

```bash
code --extensions-dir /path/to/extensions
```

### The .vscode folder in your project

The user-level `~/.vscode` folder is different from the `.vscode` folder at the root of a project. The project folder holds workspace settings like `settings.json`, `launch.json` and `extensions.json` (recommended extensions for the team).

## Keep extension data out of git

VS Code is awesome and there are so many great extensions that make life easier. Some of these extensions store data in folders which are usually placed at the root of the workspace like:

```bash
app
└───.vscode
└───.history # Local History extension folder
```

Until recently, I was adding those folders to my `.gitignore` file since they are mainly for personal/local use and didn't want to mess with my teammates' setups. This isn't cumbersome but felt a little weird, like mixing too much of my personal setup into our project.

All of our projects already have `.vscode` in the `.gitignore` file so it makes sense to move any extension folders into the `.vscode` folder and bypass adding individual folders to `.gitignore`.

```bash
app
└───.vscode
│   └───.history
```

Most extensions that have settings/data folders also have a way to link to the path. The example above is for the [Local History](https://marketplace.visualstudio.com/items?itemName=xyz.local-history) extension which has a setting called `Local History: Path`. Just drop a `${workspaceFolder}/.vscode` in there and you're good to go.

Not a huge win but it's nice that you don't have to add something to your `.gitignore` file every time you try out a new extension.
